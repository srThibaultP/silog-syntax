# SILOG Syntax Highlighting

Coloration syntaxique pour les fichiers SILOG (`.evt` et `.act`).

## Fonctionnalités

- Mots-clés de blocs : `[SI]`, `[FINSI]`, `[ALORS]`, `[SINON]`, `[POURCHAQUE]`, `[TANTQUE]`, `[EXTRAIRE]`, `[CONDITION]`…
- Fonctions : `SDVA`, `SDVE`, `SDVR`, `SEA`, `SEE`, `SAM`, `SEFA`, `SER`, `SLA`, `CHR$`, `CJUSTIFY$`, `LEFT$`, `RIGHT$`
- Commentaires `//` et chaînes de caractères
- Fermeture automatique des crochets, parenthèses et guillemets
